# 변경 기록

## 1.0.1 · 2026-10-08

- 응답 Content-Type이 빠진 정상 SSE 스트리밍 답변을 JSON으로 잘못 읽어 실제 답장 알림을 생략하던 문제를 수정했습니다. 본문의 SSE 프레임도 확인하며 오류·생각만 있는 응답에는 알림을 보내지 않습니다.
- 테스트 알림과 실제 답장 결과를 따로 저장하고 확장 설정에 시각과 함께 표시합니다. 연결 확인을 누르면 갱신되며 테스트 성공을 실제 답장 전송 성공으로 오해하지 않도록 했습니다.
- 요청의 알림 표시 누락, HTTP 오류, 응답 판별 실패, 연결 중단, 표시 조건에 따른 생략을 구분합니다. Termux 서버 로그에도 test/reply와 처리 결과를 남기며 채팅 본문·키·구독 주소는 기록하지 않습니다.

서버 플러그인과 웹 확장을 함께 업데이트하는 기존 설치 명령을 다시 실행한 뒤 서버 재시작·실리 페이지 새로고침이 필요합니다. 알림 앱 재설치나 기기 재연결은 필요 없습니다. 진행 중이거나 복구할 답장을 먼저 받은 뒤 재시작하세요.

기존 코드에서 알림 누락을 재현하고 수정 후 회귀 테스트 및 릴레이 1.0.1 연동을 검증했습니다. Apple 푸시 전송은 모의했으므로 실제 아이패드에서의 수신 확인은 별도입니다.

## 1.0.0 · 2026-10-08

- Silly-Pop iOS 첫 정식 배포. 갤럭시용 Silly-Pop과 별도로 설치합니다.
- 시험을 마친 일반 답장·재생성·스와이프 알림과 Silly Relay 연동 로직을 유지했습니다.
- 아이폰 실기기 테스트 완료를 반영하고 설치·연결·업데이트 안내를 정리했습니다.
- 시험판 표시를 제거하고 앱·확장 이름을 Silly-Pop iOS로 통일했습니다.
- 시험판 설치를 정식 버전으로 업데이트할 수 있습니다. 기존 앱 주소·구독·연결 키·설정을 유지합니다.
