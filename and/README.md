# Silly-Pop AND

안드로이드 브라우저에 설치하는 답장 알림 웹앱입니다. **확장·서버·웹앱 1.0.2 정식판**입니다. 갤럭시 삼성 인터넷에서 설치, 테스트 알림, 실제 답장 및 화면 밖 알림 수신을 확인했습니다.
기존 Silly-Pop APK 및 Silly-Pop iOS와 별도로 설치합니다.

## 무엇을 설치하나요?

1. 실리태번 확장: 메시지 요청에 알림 받을 기기를 표시합니다.
2. 서버 플러그인: 서버가 AI 답변을 다 받으면 선택한 기기에 웹 푸시를 보냅니다.
3. 알림 웹앱: 갤럭시 브라우저에서 설치하고 처음 한 번 코드로 연결합니다.

설치 명령 하나로 1·2를 함께 설치합니다. 화면을 나가거나 웹앱이 종료된 뒤에도 생성을 이어가고 답장을 복구하려면 **Silly Relay를 별도로 설치하고 켜 주세요.** AND에는 릴레이가 포함되어 있지 않습니다.

실리 서버 → Google 웹 푸시 → 갤럭시 브라우저 알림 순서입니다. 알림 웹앱을 계속 열어둘 필요가 없고 상시 실행 서비스나 수신 중 알림을 만들지 않습니다. Firebase 계정·카드·유료 중계 서버는 필요하지 않습니다. 기존 AI 사용료, 인터넷 및 서버 운영 비용은 별도입니다. 서버는 켜져 있어야 합니다.

## 설치 전

- 실리태번 서버를 완전히 종료합니다. 실행 중인 터미널에서 Ctrl+C를 누릅니다.
- Node.js 18 이상 및 Git이 필요합니다. 실리태번 설치 때 사용하는 환경을 그대로 쓰면 됩니다.
- 아래 명령은 실리태번의 기본 `data` 경로와 `default-user` 기준입니다.
- 설치 프로그램은 `server.js`와 `config.yaml`이 있는 실제 실리태번 폴더인지 확인합니다. 경로가 다르면 실제 경로를 넣어 주세요.

## 갤럭시 Termux 서버

```sh
git clone --branch and --single-branch https://github.com/foreverharibo-boop/Silly-Pop.git "$HOME/Silly-Pop-AND"
node "$HOME/Silly-Pop-AND/and/install.cjs" "$HOME/SillyTavern"
```

실리 폴더가 `TavernAI`라면 마지막 명령의 `SillyTavern`만 `TavernAI`로 바꿉니다. 다른 프로젝트 폴더의 이름을 바꾸지 마세요.

## Windows 서버 — CMD

탐색기에서 실제 실리태번 폴더를 열고 주소창에 `cmd`를 입력한 뒤 Enter를 누릅니다. 그 창에서 실행합니다.

```bat
git clone --branch and --single-branch https://github.com/foreverharibo-boop/Silly-Pop.git "..\Silly-Pop-AND"
node "..\Silly-Pop-AND\and\install.cjs" "%CD%"
```

`Silly-Pop-AND` 다운로드 폴더는 실리태번 폴더 옆에 만들어집니다. 이미 같은 이름의 폴더가 있다면 아래 업데이트 방법을 사용합니다.

## macOS / Linux 서버

```sh
git clone --branch and --single-branch https://github.com/foreverharibo-boop/Silly-Pop.git "$HOME/Silly-Pop-AND"
node "$HOME/Silly-Pop-AND/and/install.cjs" "/실제/실리태번/경로"
```

마지막 경로를 실제 경로로 바꿔 주세요. 따옴표는 유지합니다.

## 플러그인 활성화와 재시작

실리태번 폴더의 `config.yaml`에서 기존 `enableServerPlugins` 값을 `true`로 설정합니다. 동일한 항목을 중복 추가하지 마세요. 설치 프로그램은 이 파일을 자동으로 고치지 않습니다.

서버를 평소 방법으로 켜고 `[Silly-Pop AND] 1.0.2 loaded` 로그를 확인합니다. 실리 화면도 새로고침하면 확장 설정에 **Silly-Pop AND**가 나타납니다.

사용자 폴더가 `default-user`가 아니면 설치 명령 끝에 실제 사용자 폴더 이름을 붙입니다. 예: `node "../Silly-Pop-AND/and/install.cjs" "." "계정폴더이름"`.

커스텀 data 경로는 자동 설치하지 않습니다. 수동 설치 시 `and/extension` 내용과 `and/LICENSE`를 실제 사용자의 `extensions/Silly-Pop-AND`로 복사하고, `and/server`, `and/package.json`, `and/package-lock.json`, `and/LICENSE`는 `plugins/Silly-Pop-AND`에 복사합니다. 플러그인 폴더에서 `npm ci --omit=dev --ignore-scripts --no-audit --no-fund`를 실행합니다.

## 갤럭시에서 처음 연결하기

1. 안드로이드 브라우저에서 **https://silly-pop.pages.dev/** 를 엽니다.
2. 브라우저 메뉴에서 홈 화면에 추가 또는 앱 설치를 선택합니다. 설치 버튼이 보이면 그 버튼을 사용해도 됩니다. 설치한 **Silly-Pop AND** 아이콘으로 엽니다.
3. 채팅할 실리태번의 확장 설정 → **Silly-Pop AND** → **연결 확인**을 누릅니다.
4. **안드로이드 처음 연결하기**를 펼쳐 **연결 코드 만들기**를 누릅니다.
5. `SPAND1.` 코드를 알림 웹앱에 붙여 넣고 **연결 코드 확인 → 알림 허용하기**를 누릅니다.
6. 나온 `SPAND2.` 완료 코드를 실리태번의 **안드로이드 연결 완료** 칸에 넣고 완료합니다. 코드는 10분 동안 유효합니다.
7. **테스트 알림**을 보냅니다. 실제 휴대폰에 도착하는지 확인합니다.
8. Silly Relay를 켜고 일반 답장과 새 스와이프를 각각 요청한 뒤 다른 화면으로 이동해 확인합니다.

같은 브라우저에서는 보통 한 번 연결하면 됩니다. 다른 브라우저·기기에서 채팅할 경우 그 실리 화면에서 **연결 확인 → 알림 받을 기기 선택 → 답장 알림 켜기**를 설정합니다. 서버에 연결한 기기는 다시 코드 교환하지 않고 목록에서 선택할 수 있습니다.

## 알아두실 점

- **Google 서비스가 있는 안드로이드 + Google 웹 푸시를 지원하는 브라우저**에서 사용합니다. 삼성 인터넷의 실제 수신을 확인했으며 Chrome도 지원합니다. 다른 푸시 서비스의 주소는 연결하지 않습니다.
- PC/Mac/Termux 서버에 설치할 수 있도록 작성했습니다. 모든 환경을 직접 테스트한 것은 아닙니다.
- 일반 답장, 재생성, 새 스와이프의 Chat Completion 요청을 지원합니다. 이미 받은 스와이프 후보를 넘기는 동작은 알리지 않습니다. 조용한 생성·이어쓰기·사칭 생성은 대상이 아닙니다.
- 알림은 **서버의 AI 응답 수신 완료** 기준입니다. 번역이나 검수·재작성 완료를 뜻하지 않습니다. 재작성 요청이 별도 일반 생성으로 들어오면 추가 알림이 올 수 있습니다.
- **다른 화면을 볼 때만**은 요청을 보낸 실리 페이지의 표시 상태를 기준으로 합니다. 모바일이 상태 전송 전에 종료되거나 연결이 끊어지면 알림이 생략될 수 있습니다. 수신 테스트 중에는 이 옵션을 꺼서 비교할 수 있습니다.
- 알림 문구는 APK와 동일하게 **김홍진의 답장이 도착했어요**처럼 요청 시점의 캐릭터 이름을 기본으로 표시합니다. 이름을 가져오지 못하면 **답장이 도착했어요**로 표시합니다. 대화 본문·AI API 키는 알림에 포함하지 않습니다. 이름은 휴대폰 알림 표시 설정에 따라 잠금 화면에도 보일 수 있습니다.
- 알림을 누르면 AND 알림 앱으로 이동합니다. 사용하던 실리 웹앱으로 자동 복귀하는 기능은 없습니다.
- 소리·진동은 브라우저/휴대폰의 알림 설정을 따릅니다. 방해 금지, 배터리 제한, 브라우저 강제 종료 등은 수신에 영향을 줄 수 있습니다. 즉시 도착을 보장하지 않습니다.
- 전달 대기는 최대 5분입니다. 오래 오프라인이면 이전 알림은 도착하지 않을 수 있습니다. 답장 복구와 알림 전달은 별개입니다.
- 웹앱 삭제·사이트 데이터 삭제·알림 구독 만료 시 다시 연결해야 할 수 있습니다.
- 기존 APK 알림을 함께 켜 놓으면 둘 다 알릴 수 있습니다. AND 수신을 확인한 후 기존 방식의 답장 알림을 꺼 주세요.

## 개인정보 및 보안

웹앱은 HTTPS 정적 페이지입니다. 서버 주소나 실리 로그인·AI 키를 웹앱에 입력하지 않습니다. 각 실리 서버가 개별 서명 키를 만들고, 인증된 실리 계정별로 구독을 분리합니다. 캐릭터 이름을 포함한 푸시 내용은 전송 전에 암호화하며 Google의 알림 전달 서비스를 거칩니다.

서버는 `~/.config/silly-pop-and/push.json`에 서명 키와 연결 정보를 저장합니다. 이 파일과 완료 코드를 공개하지 마세요. 서버는 Google의 정해진 HTTPS 푸시 주소만 허용합니다. AND 설치 폴더·브라우저 설정·서비스 워커·구독은 iOS 및 기존 APK와 분리되어 있습니다. 코드나 설정을 바꿀 때 채팅 파일과 실리 API 키 파일은 수정하지 않습니다.

## 업데이트

서버를 종료한 뒤 내려받은 **Silly-Pop-AND 소스 폴더**에서 `git pull --ff-only`를 실행하고, 처음 사용한 `node .../and/install.cjs ...` 명령을 다시 실행합니다. 서버 재시작 후 실리 화면을 새로고침합니다.
설치 프로그램은 기존 AND 설치본을 `.silly-pop-and-backups`에 보관하고 실패하면 되돌립니다. iOS·기존 APK·Relay 설치본은 수정하지 않습니다.

## 검증 범위

자동 검사는 코드 연결, 계정 분리, 주소 검증, JSON/SSE 답장 판별, 중복 방지, 오류 처리, 웹앱 및 Relay 연동을 다룹니다. 실제 Google 푸시 전송 및 갤럭시 잠금/백그라운드 수신은 사용자 기기에서 확인해야 합니다. Windows와 macOS 실기기 설치 확인도 별도입니다.
