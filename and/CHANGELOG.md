# 변경 기록

## 확장 1.0.1 · 2026-10-09 · 화면 이탈 감지 보완

- 화면 표시 상태와 함께 포커스를 확인하고, 포커스를 잃거나 페이지를 나갈 때 백그라운드 상태를 전송합니다.
- 탭마다 별도 알림 식별자를 사용해 같은 주소의 다른 실리 탭이 화면 상태를 덮어쓰지 않게 했습니다.
- keepalive 전송이 거절되면 일반 전송으로 한 번 재시도하며, 서버 전달 여부와 실패 이유를 확장에 표시합니다.
- 업데이트 후 메시지를 보내는 실리 페이지를 새로고침해야 합니다. 서버와 웹앱은 1.0.1을 유지하며 기존 기기 연결도 유지합니다.
- 포커스·화면 복귀·탭 분리·전송 실패는 자동 검사로 확인했습니다. 삼성 인터넷 홈 화면 전환은 실제 기기에서 재확인이 필요합니다.

## 서버 1.0.1 · 2026-10-09 · 압축 응답 알림 수정

- 버텍스 등 비스트리밍 정상 답변이 HTTP 압축으로 전달될 때 실제 답장으로 판별하지 못하던 문제를 수정했습니다.
- gzip·deflate·Brotli 응답의 사본을 압축 해제한 뒤 판별합니다. 채팅으로 전달하는 원본 응답은 변경하지 않습니다.
- 압축 해제 후에도 크기 한도를 적용하며 API 오류·손상된 응답·생각 내용만 있는 응답에는 알림을 보내지 않습니다.
- 서버 플러그인 업데이트와 실리태번 재시작이 필요합니다. 확장·웹앱 버전과 기존 알림 연결은 유지됩니다.

## 웹앱 1.0.1 · 2026-10-09 · 아이콘 수정

- 기존 APK 원본을 기준으로 홈 화면 로고의 크기와 여백을 맞췄습니다.
- 상태표시줄용 단색 아이콘과 알림창용 아이콘을 분리해 각각 APK 비율을 적용했습니다.
- 아이콘 URL과 웹앱 캐시 버전을 갱신했습니다. 기존 연결·구독은 유지하며 PC 확장/서버 재설치는 필요 없습니다.
- 설치된 홈 화면 아이콘의 반영 시점과 알림 레이아웃은 브라우저/런처에 따라 다릅니다. 실제 기기에서 최종 확인이 필요합니다.
- 브라우저가 표시하는 사이트 주소와 팝업 알림 중요도는 이 아이콘 수정으로 바뀌지 않습니다.

## 1.0.0 · 2026-10-09 · 테스트판

- 안드로이드 Chrome용 웹 푸시 연결과 별도 설치 프로그램을 추가했습니다.
- Google 푸시 주소만 허용하고 연결 코드, 기기 정보, 서비스 워커를 iOS와 분리했습니다.
- 기존 iOS 1.0.2의 요청 표시·답장 판별·테스트/실제 답장 진단을 반영했습니다.
- Silly Relay를 통한 생성과 새 스와이프 알림을 지원합니다.
- 갤럭시 실제 수신 확인 전입니다. 기존 APK와 iOS 배포본은 변경하지 않았습니다.
