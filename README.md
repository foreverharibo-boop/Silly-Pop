# Silly-Pop (실리팝)

SillyTavern 답변 생성이 끝나면 **같은 휴대폰의 Android 앱**으로 알림을 보내는 확장입니다.
웹 확장 1.4.0 · 서버 플러그인 2.2.0 · Android 앱 0.2.2.

SillyTavern/SillyTavern-PushNotifications(Cohee1207)의 포크이며, 모바일·Android 연동은 담은이 추가했습니다.
라이선스: AGPL-3.0-or-later.

## 이번 변경

- 브라우저 알림 기능과 권한 요청·답변 미리보기 제거: Android 앱 알림만 사용
- 작은 흑백 선택 버튼, 화면과 아이콘 색상 동시 변경
- 곡선형 ST 로고와 넓어진 런처 여백, 앱 UI 단순화
- 제한된 시스템 am 대신 Termux용 am 사용, 현재 Android 프로필 지정
- 앱의 실제 응답을 확인하고 서버·앱 버전과 오류 원인 표시
- 확장 본인 소유의 이전 알림 워커만 정리 (다른 확장·PWA는 유지)

## 설치·업데이트

### Android 앱

[APK 다운로드](https://github.com/foreverharibo-boop/Silly-Pop/releases/tag/v0.2.2-test)

0.2.1부터 고정 서명을 사용합니다. **0.2.1 → 0.2.2는 삭제하지 않고 덮어 설치**합니다.
0.2.0 이하는 서명이 달라 기존 앱을 한 번 삭제해야 하며 앱 설정이 초기화됩니다.
설치 후 앱을 한 번 열어 알림 권한을 허용하고 테스트 알림을 눌러 주세요.

### 웹 확장

실리태번 확장 관리에서 아래 저장소를 설치하거나 업데이트하고 새로고침하세요.

```text
https://github.com/foreverharibo-boop/Silly-Pop
```

### 서버 플러그인 (웹 확장과 별도로 업데이트해야 합니다)

같은 휴대폰의 Termux에서 실행합니다. Termux:API 앱은 필요하지 않습니다.

```bash
pkg install termux-am
cd ~/SillyTavern
node plugins.js install https://github.com/foreverharibo-boop/Silly-Pop
```

이미 기본 경로에 설치했다면:

```bash
git -C ~/SillyTavern/plugins/Silly-Pop pull --ff-only
```

설치 폴더를 직접 바꿨다면 해당 폴더 경로를 사용하세요.
config.yaml의 enableServerPlugins: true가 필요합니다.
업데이트 뒤 **실리태번 서버 프로세스를 완전히 종료하고 다시 시작**하세요.
확장 설정 아래에 **확장 1.4.0 · 서버 2.2.0 · 앱 0.2.2**가 표시되는지 확인한 뒤 연결 확인과 테스트 알림을 누르세요.

## 연결 문제

- 앱 안의 알림 허용은 서버 연결 성공을 의미하지 않습니다.
- 서버 버전이 예전이면 서버 플러그인을 업데이트하고 재시작하세요.
- Termux용 am이 없으면 pkg install termux-am을 실행하세요.
- 앱 응답이 없으면 앱을 한 번 열고 다시 확인하세요. 진단 내용이 확장 설정에 표시됩니다.
- 서버가 PC에 있으면 휴대폰에 설치한 앱을 이 방식으로 호출할 수 없습니다.
- 프로세스 종료나 휴대폰의 절전 정책 등 실제 기기 환경은 별도 확인이 필요합니다.

## 동작과 개인정보

서버가 표시가 붙은 메인 생성 응답의 종료를 감지해 명시적 브로드캐스트로 앱을 호출합니다.
다른 앱을 볼 때만, 소리, 진동을 설정할 수 있습니다.
숨은 생성(quiet)과 impersonate는 제외하고 동일 요청의 중복 알림을 막습니다.
알림 본문은 고정 완료 문구이며, 알림을 누르면 생성 당시 실리태번 주소를 브라우저로 엽니다.
서버와 브라우저가 종료돼 있으면 새로운 생성 완료 알림은 만들 수 없습니다.

Android 앱은 알림 권한만 요청합니다. 인터넷·파일·사진·연락처·문자·접근성 권한과 상시 실행 서비스가 없습니다.
외부 푸시 서버나 추가 AI API 크레딧을 사용하지 않습니다.
