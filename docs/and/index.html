답장이 오면 알려드려요.

알림 준비 중이에요.

안드로이드 Chrome에서 열고 메뉴 → 홈 화면에 추가 → 설치를 선택해 주세요.

설치한 아이콘으로 열어 연결해 주세요. 기존 실리팝 APK와 별개의 알림 앱이에요.

01 실리와 연결

실리태번의 Silly-Pop AND에서 만든 연결 코드를 넣어 주세요.

02 알림 켜기

처음 한 번만 허용하면 돼요. 알림 앱을 계속 열어둘 필요는 없어요.

03 마지막으로 한 번만!

완료 코드를 실리태번의 안드로이드 연결 완료 칸에 붙여 넣어 주세요.

실리에서 연결을 마친 뒤 테스트 알림을 보내 주세요. 이 화면만으로는 서버 연결 완료 여부를 확인할 수 없어요.

알림이 안 오나요?

안드로이드 설정에서 이 앱의 알림 권한과 방해 금지 모드를 확인해 주세요. 실리 서버도 켜져 있어야 해요.

홈 화면에서 앱을 삭제했거나 사이트 데이터를 지웠다면 다시 연결해 주세요.

대화 내용과 AI 키를 받지 않아요.
알림 전송에는 Google 푸시 서비스를 사용해요.
